Power BI – Data Loading

Objective

Load the project data from Azure Databricks into Power BI Desktop for analysis and visualization.

Tables

The following project tables were loaded/accessed in Power BI:

- "bronze_electronics_products"
- "electronics_products_pricing"
- "silver_electronics_products"

Steps

1. Connect Power BI Desktop to Azure Databricks.
2. Select the required project tables.
3. Preview the available data.
4. Select Load.
5. Wait for the data to load into Power BI.
6. Verify the loaded tables in the Power BI Data/Model view.

Outcome

Successfully connected Azure Databricks with Power BI Desktop and loaded the required Bronze and Silver project data for further analysis and visualization.
