Power BI – Azure Databricks Connection

Objective

Connect Power BI Desktop with Azure Databricks to access the project data.

Steps

1. Open Power BI Desktop.
2. Select Get Data → Azure → Azure Databricks.
3. Enter the Databricks Server Hostname and HTTP Path provided for the project.
4. Select Personal Access Token authentication.
5. Enter the generated access token.
6. Click Connect.
7. Select the required database and tables.

Outcome

Successfully connected Power BI Desktop with Azure Databricks and accessed the project data.
